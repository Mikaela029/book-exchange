# Troca de livros
 
## Description

O objetivo do projeto é possibilitar a troca de livros usados entre utilizadores. Estes colocam os livros disponíveis para troca, e outros utilizadores podem oferecer outros livros para troca.

## Main Entities (Data Bases)
-utilizadores (nome, mail, username, password, catalago de livros, histórico de trocas)
-livros (nome, autor, estado, língua)
-ofertas (livros, proximidade)
-propostas (livros, proximidade)

## Main Business Rules
 
Funcionalidades:
Validação da identidade (com username/passe)
Bibliotecas dos utilizadores
Registar trocas de livros
